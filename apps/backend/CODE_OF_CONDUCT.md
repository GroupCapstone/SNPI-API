# Code of Conduct

## Our standard

Contributors must help keep project discussions and collaboration respectful, inclusive, and focused on the work. Harassment, discrimination, threats, personal attacks, and publishing another person's private information are not acceptable.

## Expected behavior

- Be respectful when reviewing code or disagreeing about a design.
- Give feedback about the work, not the person.
- Protect student, staff, and account information.
- Follow the project's security reporting process for vulnerabilities.

## Enforcement

Repository maintainers may edit or remove content and limit participation when behavior violates this policy. Report conduct concerns privately to a repository owner through GitHub. For security reports, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

This policy applies to repository issues, pull requests, code reviews, and project-related communication.
