## 3. Operational Policy: Standby Knowledge

* **Strict Zero Premature Code Application**: This library serves as authoritative pre-learned architectural knowledge. No monorepo code or existing REST endpoints in `apps/backend` or `@snp/shared` should be altered until an explicit command is issued by the user.
* **Command to Activate**: When the user asks to design, refactor, or audit REST endpoints according to API Stylebook principles, agents must consult the corresponding topic knowledge file and follow its exact rules.
